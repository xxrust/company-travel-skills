# 住宿标准与价格查询

## 公司规则

住宿费以离出差点最近的汉庭酒店为标准；如果附近没有汉庭，再以离出差点最近的全季酒店为标准。

## 查询规则

1. 必须提供出差点、入住日期和离店日期。
2. 先搜索汉庭，再搜索全季；记录酒店名称、距离、房型、每晚价格、税费、价格来源和查询时间。
3. 价格会随日期、房型、会员身份、早餐和税费变化。不能从搜索摘要或文件名推断报销金额。
4. 只有人工确认了酒店和可核验报价后，才把价格写入报销明细；否则写“待人工查询”。
5. 使用 `scripts/hotel_benchmark.py` 生成查询记录和浏览器搜索链接。

示例：

```powershell
python scripts/hotel_benchmark.py `
  --location "示例城市 示例项目" `
  --check-in 2026-01-10 `
  --check-out 2026-01-12 `
  --output .\cases\TRIP-2026-001\03-发票凭证\hotel-benchmark.json `
  --open-browser
```
