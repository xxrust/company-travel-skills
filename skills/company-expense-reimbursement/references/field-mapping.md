# Workbook field mapping

## `报销单`

WPS/XLSX 纸面表固定 10 列，第 8 至 13 行共 6 行明细；超过 6 行调用 `add_reimbursement_page(...)` 追加同版式表。直接用 WPS 导出 PDF，A4 纵向，一表一页。

| 区域 | 含义 |
|---|---|
| `A3:J3` | 部门标签与内容 |
| `B4:C4` / `E4` / `G4:J4` | 姓名、职别、出差事由 |
| `A5:B5` / `C5:G5` | 起止日期标签、完整日期与天数 |
| `H5:J5` | 正式报销单据数量，不含辅助结账单 |
| `A8:A13` | 起讫日期，完整月日，禁止拆行 |
| `B8:B13` | 起讫地点，方向写成 `A→B` |
| `C8:C13` / `D8:D13` | 车船费名称和金额 |
| `E8:E13` | 宿费，按 A→B 规则挂在对应行 |
| `F8:F14` | 出差补助及小计，全部留空，由财务填写 |
| `G8:G13` | 市内交通费 |
| `H8:H13` / `I8:I13` | 杂费用途和金额 |
| `J8:J13` | 特殊情况说明；没有特殊情况时留空 |
| `D14` / `E14` / `G14` / `I14` | 非补助分类小计，隐藏第14行，不在纸面增加合计行 |
| `A15:F15` / `G15:I15` | 大写标签与空白区、固定“￥：”标记；两区间无竖线，附注列右侧边界延续到本行，金额由财务填写 |
| `A16:C16` / `D16:G16` / `H16:J16` | 单位主管、复核、出差人标签及空白签名区，位于外框下方 |

白底蓝字表头（第 6、7 行）；签名区域留空。

旧版 16 列转换时，原四格出发/到达日期时间保留到单独原始行程表，避免纸面日期合并造成信息丢失。旧 H/I/K/M 费用映射为新 D/E/G/I；汇总脚本兼容旧布局。使用 WPS 导出的 PDF 验证实际布局，不用模拟渲染代替。

## `发票明细`

每份发票或辅助凭证一行，保留源文件、页码、票据号、日期、购买方字段、金额、入住/离店日期、路线、分类、是否可报销和校验状态。来源索引写在这里，不写进纸面报销单附注。

## `校验与说明`

保存本地公司主数据、运行规则和人工复核事项。私有身份数据不写入公开 skill 仓库。
