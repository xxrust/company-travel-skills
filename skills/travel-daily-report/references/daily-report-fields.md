# 出差每日汇报字段

## Required fields

| Field | Content |
|---|---|
| 日期和报告人 | 明确是哪一天、谁提交 |
| 所在地/路线 | 实际地点和当天移动；未知时标记待补充 |
| 今日任务 | 计划任务与实际完成情况分开 |
| 完成结果 | 用可核查的结果描述，不用空泛的“已沟通” |
| 证据 | 图片、会议纪要、测量记录、客户消息或文件路径 |
| 明日计划 | 下一步动作、负责人和预期时间 |
| 异常与需求 | 延误、路线变化、客户问题、费用或安全问题 |

## Status values

Use `已完成`, `进行中`, `延期`, `阻塞`, `待补充`, and `未提交`. If a report is backfilled, say who supplied the facts and when.

## Evidence rule

The report may summarize a source, but it must not turn an unverified plan into a completed result. When the user provides only a short message, preserve the message as the source note and leave unsupported details blank.
