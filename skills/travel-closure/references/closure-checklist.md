# 出差收尾检查表

## Route and time

- [ ] 实际开始和结束日期明确。
- [ ] 实际路线按时间顺序排列。
- [ ] 起点、目的地和返程有来源证据。
- [ ] 路线回到初始起点；否则标记 `路线未闭环`。
- [ ] 计划路线与实际路线差异已说明。

## Work and daily records

- [ ] 每日汇报覆盖出差期间，缺失日期已显式列出。
- [ ] 每项主要任务有结果或明确的未完成状态。
- [ ] 关键结果有附件、消息、会议记录或用户确认。
- [ ] 后续行动有负责人和时间。

## Reimbursement readiness

- [ ] 票据已登记并关联到案件或具体行程段。
- [ ] 住宿票有入住和离店日期。
- [ ] 公司购买方信息已核对。
- [ ] 金额、日期、地点或抬头的冲突已列入问题清单。
- [ ] 签名位置保持空白，等待手写。

## Status decision

只有路线、每日记录和成果检查通过，且没有阻塞问题时，才可将案件置为 `ready_for_reimbursement`。存在待人工复核的问题时，输出“可继续补充材料”，不要输出“已完成”。
