# 出差申请字段

## Required planned fields

| Field | Requirement |
|---|---|
| 案件 ID | 与 `case.yaml.case_id` 一致 |
| 部门、姓名、职别 | 使用用户或公司主数据，不自行推断 |
| 出差事由 | 写清业务目标和预期输出 |
| 计划起止日期 | 使用 ISO 日期；跨天必须明确 |
| 计划路线 | 按顺序写起点、目的地和预计返程 |
| 交通和住宿计划 | 区分计划与已发生费用 |
| 预计预算 | 交通、住宿、补助、其他分别记录；未知项标记待补充 |
| 审批人/审批状态 | 未确认时保留空值或待补充 |
| 附件 | 任务单、客户邀请、行程单等，登记文件路径 |

## Review checks

- 起点和终点是否明确，计划路线是否包含返程安排。
- 计划日期是否覆盖所有计划停留日。
- 预算是否和路线、住宿天数大致一致；异常只提示，不擅自修改。
- 申请中的目的、人员和部门是否与案件记录一致。
- 需要签名的位置保持空白，审批状态必须有证据。
