# 差旅案件目录布局

建议每次出差一个目录，目录名可以包含案件 ID 和人员姓名：

```text
TRIP-2026-001_姓名/
├─ case.yaml
├─ issues.md
├─ 01-出差申请/
├─ 02-出差过程/
├─ 03-发票凭证/
├─ 04-出差结束/
└─ 05-报销/
```

## Artifact naming

- 申请：`出差申请_案件ID_版本或日期.xlsx` 或 `.md`
- 日报：`YYYY-MM-DD_每日汇报.md`
- 收尾：`出差总结_案件ID.md`
- 报销：`差旅费报销单_案件ID.xlsx`
- 原始凭证：保留原文件名，并在 `case.yaml` 中登记 `document_id`。

不要用同一个文件同时保存申请、日报和收尾内容。每个文件对应一个阶段，案件索引负责关联它们。
